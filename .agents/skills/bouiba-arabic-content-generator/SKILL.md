# Bouiba Arabic Content Generator

## الهدف

هذه المهارة مخصصة لتوليد مقالات تقنية عربية عالية الجودة لمدونة Bouiba Academy بصيغة منظمة وقابلة للحفظ داخل المشروع.

## متى تستخدم

استخدم هذه المهارة عندما يكون المطلوب:
- إنشاء مقال عربي تقني من موضوع أو كلمة مفتاحية
- بناء outline عربي منظم
- توليد عنوان، وصف، كلمات مفتاحية، وأسئلة شائعة
- كتابة مسودة Markdown عربية واضحة ومهنية
- تجهيز حزمة محتوى قابلة للمراجعة أو النشر لاحقاً

## تعريف المدونة

- اسم المدونة: Bouiba Academy
- التخصص: الذكاء الاصطناعي، الأتمتة، n8n، Make، APIs، Ollama، Google Cloud، Blogger، SEO التقني
- الجمهور: المطورون، الفريلانسرز، منشئو الأنظمة الآلية، وصناع المحتوى التقني
- الأسلوب: عربي فصيح، عملي، مباشر، احترافي، بدون حشو
- النبرة: تعليمية، واضحة، موجهة للتطبيق

## سير العمل المطلوب

عند استخدام هذه المهارة، اتبع الخطوات التالية بالترتيب:

1. اطلب الموضوع أو الكلمة المفتاحية إذا لم يتم توفيرها.
2. اقترح 3 زوايا ممكنة للمقال.
3. اختر أفضل زاوية مناسبة لجمهور Bouiba Academy.
4. أنشئ العناصر التالية:
   - عنوان رئيسي
   - 5 عناوين بديلة مناسبة للسيو
   - slug باللغة الإنجليزية
   - excerpt مختصر
   - meta description
   - كلمات مفتاحية رئيسية وثانوية
   - outline منظم بعناوين H2 و H3
   - المقال كاملاً بصيغة Markdown
   - FAQ من 4 إلى 6 أسئلة
   - prompt لصورة الغلاف
5. إذا كان الموضوع تقنياً:
   - أضف خطوات تنفيذ عملية
   - أضف أمثلة حقيقية
   - أضف snippets كود عند الحاجة
   - أضف قسم الأخطاء الشائعة
   - أضف best practices
6. إذا كانت هناك معلومة غير مؤكدة، اذكر أنها افتراض ولا تختلق حقائق.
7. الخطوة الأخيرة بعد التوليد: تأكيد الـ slug، وتأكيد الملفات التي تم إنشاؤها أو تحديثها، وتقديم ملخص قصير للمحتوى الناتج.

## معايير الجودة

### جودة المقال
- ابدأ بمقدمة مفيدة وقصيرة
- تجنب المقدمات الإنشائية العامة
- ركز على الفائدة العملية
- استخدم Markdown منظم وواضح
- اجعل المحتوى مناسباً للقراءة التقنية العربية
- استخدم أمثلة قريبة من الواقع

### جودة السيو
- العنوان طبيعي ومحدد
- الوصف التعريفي مختصر وفعّال
- الكلمات المفتاحية مرتبطة مباشرة بنية البحث
- البنية الداخلية للمقال تدعم الفهم والأرشفة

## بنية الملفات

احفظ الناتج في هذا المسار:
- content/posts/[slug]/post.md
- content/posts/[slug]/meta.json
- content/posts/[slug]/cover-prompt.txt

### post.md
يحتوي على:
- عنوان H1
- المقال كاملاً بصيغة Markdown
- عناوين H2 و H3
- القوائم والأمثلة والكود عند الحاجة
- قسم FAQ في النهاية

### meta.json
يحتوي على JSON صالح بالمفاتيح التالية:
- title
- slug
- excerpt
- meta_description
- target_keywords
- category
- tags
- created_at
- language

مثال:

```json
{
  "title": "كيفية ربط Ollama مع n8n لبناء أوتوماتيون محلي",
  "slug": "ollama-n8n-local-automation",
  "excerpt": "شرح عملي لربط Ollama مع n8n لإنشاء تدفقات أتمتة محلية تعتمد على نماذج ذكاء اصطناعي مفتوحة.",
  "meta_description": "دليل عملي لربط Ollama مع n8n وبناء أتمتة محلية باستخدام نماذج ذكاء اصطناعي مفتوحة.",
  "target_keywords": ["Ollama", "n8n", "local AI automation"],
  "category": "AI Automation",
  "tags": ["Ollama", "n8n", "Automation", "Local AI"],
  "created_at": "2026-07-17",
  "language": "ar"
}
```
