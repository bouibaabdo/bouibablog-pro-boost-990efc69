## الهدف
السماح برفع فيديوهات حتى **500MB** في قسم دروس الفيديو (`/admin/lessons`).

## الخطوات

1. **تحديث حد bucket `lessons` في Supabase Storage**
   - عبر migration: `UPDATE storage.buckets SET file_size_limit = 524288000 WHERE id = 'lessons';` (500 × 1024 × 1024)
   - التأكد من `allowed_mime_types` تشمل `video/*`.

2. **تحسين واجهة الرفع في `src/routes/_authenticated/admin/lessons.tsx`**
   - إضافة تحقق على جانب العميل قبل الرفع: رفض الملفات > 500MB مع رسالة عربية واضحة.
   - إظهار حجم الملف والحد الأقصى في نص المساعدة تحت حقل الاختيار.
   - رفع timeout الطلب إن لزم (Supabase JS يدعم الرفع الكبير افتراضياً بدون مشاكل حتى هذا الحجم).

3. **إرشاد المستخدم**
   - إضافة ملاحظة صغيرة: «الحد الأقصى 500MB. للفيديوهات الأطول، يُنصح بضغطها إلى 720p قبل الرفع لتسريع التحميل.»

## ملاحظات تقنية
- 500MB = 524,288,000 bytes.
- لا حاجة لتغيير أي شيء في `lessons.functions.ts` — الحد يُطبَّق على مستوى bucket + العميل.
- الرفع الحالي يستخدم `supabase.storage.upload()` المتوافق مع الأحجام الكبيرة عبر multipart resumable داخلياً.
