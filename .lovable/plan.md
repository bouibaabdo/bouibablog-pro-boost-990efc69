## المشكلة

1. **الفيديو لا يشتغل**: باكيت `lessons` خاص، وسياسات التخزين لا تسمح إلا للأدمن بالقراءة. دالة `listLessons` العامة تُنشئ Signed URL بمفتاح `anon` — فيرجع `null` والفيديو لا يُحمَّل.
2. **لا توجد صورة مصغّرة**: تُطلب يدويًا من الأدمن.

## الحل

### 1) توقيع الروابط من طرف الخادم بامتيازات كاملة
في `src/lib/lessons.functions.ts`، داخل `listLessons` (والإدارية أيضًا) استخدم عميل الأدمن لتوقيع الروابط (لا يُسرَّب المفتاح — يبقى في الـ handler، ويُعاد فقط رابط موقّت لـ 24 ساعة):
```ts
const { supabaseAdmin } = await import("@/integrations/supabase/client.server");
// استعمل supabaseAdmin.storage.from("lessons").createSignedUrl(...)
```
تبقى قراءة صفوف الجدول عبر عميل `anon` (RLS مطبَّق)، والتوقيع فقط يتم عبر الأدمن.

### 2) توليد صورة مصغّرة تلقائيًا
- إنشاء باكيت عام جديد `lesson-thumbs` (via migration) مع سياسة SELECT عامة وINSERT للأدمن.
- في صفحة الأدمن، بعد اختيار الفيديو مباشرة (قبل الرفع): تحميل الفيديو في عنصر `<video>` مخفي، القفز إلى الثانية 1، رسم الإطار على `<canvas>` بحجم 640×360، تحويله إلى JPEG blob.
- بعد ضغط "رفع الفيديو": رفع المصغّرة إلى `lesson-thumbs/{videoId}.jpg` بالتوازي مع الفيديو، وتخزين URL العام تلقائيًا في `thumbnail_url`.
- يبقى حقل «رابط صورة مصغّرة» متاحًا للأدمن كإلغاء يدوي (اختياري).

### 3) واجهة الأدمن
- عرض معاينة المصغّرة المولَّدة تلقائيًا داخل بطاقة الرفع مع زر «إعادة التوليد» يسمح باختيار لحظة مختلفة عبر شريط تمرير بسيط (0–100% من مدة الفيديو).

## الملفات المعدّلة

- `supabase/migrations/*_lesson_thumbs.sql` — باكيت `lesson-thumbs` عام + سياسات storage.
- `src/lib/lessons.functions.ts` — استعمال `supabaseAdmin` لتوقيع روابط الفيديو في `listLessons` و`adminListLessons`.
- `src/routes/_authenticated/admin/lessons.tsx` — التقاط الإطار، الرفع، شريط اختيار اللحظة، معاينة المصغّرة.

## التحقق

- رفع فيديو تجريبي جديد → تظهر مصغّرة مولَّدة → النشر → فتح `/lessons` → الفيديو يعمل والصورة تظهر.
- الدروس القديمة المرفوعة قبل الإصلاح ستشتغل تلقائيًا بمجرد إصلاح التوقيع (بدون مصغّرة إن لم تُضَف يدويًا).
