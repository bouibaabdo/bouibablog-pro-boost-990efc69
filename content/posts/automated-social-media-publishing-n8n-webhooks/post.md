# أتمتة النشر التلقائي على فيسبوك وتليجرام باستخدام n8n و Webhooks

يُعتبر النشر اليدوي المكرر على صفحات فيسبوك وقنوات تليجرام عند صدور كل مقال أو منتج جديد مهدرة حقيقية للوقت والجهد. من خلال الاستفادة من منصة الأتمتة المفتوحة **n8n**، يمكنك بناء نظام أتمتة متكامل يستمع لخلاصات مدونتك (RSS/JSON) أو يتلقى إشعار **Webhook** فور نشر المقال، ليقوم بإنشاء منشور جذاب وإرفاق رابط المقال في أول تعليق ونشره تلقائياً خلال ثوانٍ!

في هذا الدليل التفصيلي، نوضح لك كيفية ربط وتجميع هذا الـ Workflow الاحترافي خطوة بخطوة.

---

## المكونات المطلوبة لبناء سيناريو الأتمتة

1. **نسخة n8n شغالة:** محلياً أو على سيرفر سحابي (Cloud/VPS).
2. **Facebook Page Access Token:** توكن صلاحيات النشر على صفحتك في فيسبوك عبر Meta Graph API.
3. **Telegram Bot Token & Chat ID:** بوت تليجرام مجاني يتم إنشاؤه عبر BotFather.
4. **خلاصة RSS أو Webhook من موقعك.**

---

## الخطوة الأولى: إعداد الموزع التلقائي (Trigger)

في منصة n8n، أنشئ Workflow جديداً واختر أحد المحفزات التالية:

- **RSS Feed Trigger:** يراقب مدونتك كل 15 دقيقة ويجلب أي مقال جديد.
- **Webhook Trigger:** يتلقى إشعاراً فورياً من موقعك عند الضغط على زر "نشر المقال".

---

## الخطوة الثانية: صياغة وتجهيز نص المنشور

أضف عقدة **Code Node** أو **Set Node** لتنسيق نص المنشور باللغة العربية وتزويده بالرموز التعبيرية والوسوم المناسبة:

```javascript
// مثال كود JS لتنسيق نص منشور فيسبوك وتليجرام داخل n8n
const item = JSON.parse(JSON.stringify($json));

const title = item.title || "مقال جديد على المدونة";
const excerpt = item.excerpt || item.description || "";
const url = item.url || item.link;

const facebookPostText = `🚀 ${title}\n\n💡 ${excerpt.slice(0, 180)}...\n\n👇 اقرأ المقال والتطبيق العملي كاملاً مجاناً من الرابط المثبت في أول تعليق! 💬\n\n#BouibaAcademy #أتمتة #n8n #الذكاء_الاصطناعي`;
const commentLink = `🔗 رابط المقال كاملاً:\n${url}`;

return {
  facebookPostText,
  commentLink,
  url,
  title,
};
```

## الخطوة الثالثة: الربط مع Meta Graph API (فيسبوك)

1. أضف عقدة **HTTP Request Node** في n8n.
2. اعبط الإعدادات كالتالي:
   - **Method:** `POST`
   - **URL:** `https://graph.facebook.com/v19.0/YOUR_PAGE_ID/feed`
   - **Body Parameters:**
     - `message`: `={{ $json.facebookPostText }}`
     - `access_token`: `YOUR_PAGE_ACCESS_TOKEN`

### إضافة الرابط في التعليق الأول تلقائياً:

أضف عقدة HTTP Request ثانية مرتبطة بالعقدة الأولى للنشر في التعليق:

- **URL:** `https://graph.facebook.com/v19.0/{{ $json.id }}/comments`
- **Body:** `message={{ $json.commentLink }}`

---

## الخطوة الرابعة: الربط مع بوت تليجرام

أضف عقدة **Telegram Node** في n8n:

1. اختر الإجراء **Send Message**.
2. اختر الحساب المغذى بـ **Bot Token**.
3. ضع الـ **Chat ID** الخاص بقناتك أو مجموعتك.
4. في خانة النص ضع: `={{ $json.facebookPostText + "\n\n" + $json.commentLink }}`.

## فوائد هذا السيناريو لنمو مدونتك

- **توفير 10+ ساعات أسبوعياً** كانت تضيع في النسخ واللصق اليدوي.
- **زيادة التفاعل والحفاظ على الخوارزميات:** يعشق فيسبوك المنشورات التي تضع الرابط الخارجي في أول تعليق لتفادي تقليل النطاق (Reach Penalty).
- **نشر متزامن وفوري:** يضمن وصول مقالك لجمهورك في لحظة صدوره.

## أسئلة شائعة (FAQ)

### هل يتطلب الأمر مهارات برمجية عالية؟

لا، n8n منصة تعتمد على السحب والإفلات (No-Code/Low-Code)، والكود البسيط الموضح أعلاه جاهز للاستخدام المباشر.

### ماذا يحدث إذا انتهت صلاحية توكن فيسبوك؟

ينبغي استخدام **Page Access Token دائم (Never-Expiring Token)** يتم توليده عبر خطوتين من Meta Developer Console لتجنب انقطاع النشر.

### هل يمكن أتمتة منصات أخرى مثل X (تويتر سابقاً) أو LinkedIn؟

نعم بالكامل، تتوفر عقد جاهزة في n8n لربط LinkedIn و X و Discord بنفس الطريقة.
