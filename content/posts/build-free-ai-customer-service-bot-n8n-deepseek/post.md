# كيفية بناء بوت خدمة عملاء ذكي ومجاني بالكامل باستخدام n8n وDeepSeek R1

تعد خدمة العملاء السريعة والدقيقة أحد أهم العوامل لنجاح أي مشروع أو متجر إلكتروني. لكن الاستعانة بموظفين على مدار الساعة أو دفع اشتراكات شهرية ضخمة لبرمجيات الشات بوت المدفوعة قد يكون عبئاً مالياً كبيراً للمشاريع الناشئة والفريلانسرز.

في هذا الشرح العملي، سنتعلم كيف تبني **وكيل أتمتة (AI Agent)** مجاني 100% يقوم بالرد التلقائي الذكي على العملاء عبر التليجرام أو الواتساب أو موقعك الشخصي باستخدام منصة **n8n** والنموذج الفائق **DeepSeek R1** بدون دفع سنتم واحد!

---

## المكونات التقنية المطلوبة (مجانية بالكامل)

1. **منصة n8n الذاتية (Self-Hosted n8n)**: تشغيل n8n محلياً أو على سيرفر مجاني.
2. **نموذج DeepSeek R1**: ربطه مجاناً عبر Ollama أو Groq Cloud API.
3. **Telegram Bot API / Webhook**: لربط واجهة المحادثة مجاناً مع المستخدمين.
4. **ذاكرة تفاعلية (Memory Buffer)**: لحفظ سياق الحوار بين البوت والعميل.

---

## الخطوة 1: تجهيز محرك الذكاء الاصطناعي DeepSeek R1

نستطيع استخدام نموذج DeepSeek R1 بإحدى طريقتين مجانيتين:
* **الطريقة الأولى (محلية)**: عبر أداة `Ollama` بربط نود n8n المحلية.
* **الطريقة الثانية (سحابية مجانية)**: عبر الحصول على API Key مجاني من Groq أو OpenRouter.

---

## الخطوة 2: إنشاء ميزات وتدفق العمل في n8n

قم بفتح منصة n8n وأضف العقد (Nodes) التالية لتكوين التسلسل البرمجي:

### 1. عقده الإستقبال (Webhook / Telegram Trigger)
تستقبل الرسائل القادمة من العميل وفحص المحتوى النصي والمعرف الخاص بالعميل (`chat_id`).

### 2. عقده ذاكرة المحادثة (Window Buffer Memory)
تسمح للبوت بتذكر الرسائل السابقة حتى يتفاعل كإنسان طبيعي يفهم السياق ولا يعيد الأسئلة.

### 3. عقده الـ AI Agent المجهزة بـ DeepSeek R1
هنا يكمن العقل المدبر. قم بضبط الـ Prompt الرئيسي ليكون البوت مهذباً ومباشراً وموجهاً لخدمة عملائك.

```json
{
  "system_prompt": "أنت مساعد خدمة العملاء الرسمي لأكاديمية Bouiba. إجاباتك ودودة، مختصرة، واحترافية باللغة العربية. إذا لم تكن متأكداً من معلومة معينة، اطلب من العميل التواصل مع الدعم الفني المباشر."
}
```

## الخطوة 3: ربط البوت بقاعدة معرفية (RAG) لإجابة أسئلة المتجر

كي لا يختلق البوت إجابات من خياله، يمكنك ربطه بملف الأسئلة الشائعة (FAQ JSON) أو قاعدة بيانات مجانية مثل Supabase Postgres.

> [!NOTE]
> **ميزة RAG التلقائية**: عندما يسأل العميل عن أسعار الكورسات أو سياسة الاسترجاع، يقرأ n8n المستند أولاً ويُغذي النموذج بالإجابة الدقيقة قبل أن يرد على العميل.

## الخطوة 4: تجربة البوت والتحقق من الاستجابة

عند إرسال العميل لرسالة مثل:
> "أهلاً، ما هي الدورات المتاحة لديكم وما هي أسعارها؟"

يقوم البوت خلال أقل من ثانيتين بقراءة الاستفسار، الاستعانة بـ DeepSeek R1، وصياغة إجابة عربية طبيعية كالتالي:
> "أهلاً بك! نقدم في أكاديمية Bouiba مسارات متكاملة في أتمتة n8n، والذكاء الاصطناعي، وSEO التقني. جميع الأدوات والدلائل الأساسية متاحة مجاناً عبر موقعنا. كيف يمكنني مساعدتك اليوم؟"

## فوائد هذا النظام مقارنة بالشات بوت التقليدي

1. **مرونة فائقة**: يفهم العامية العربية واللغة الإنجليزية والأخطاء الإملائية.

## أسئلة شائعة (FAQ)

### هل يتطلب تشغيل n8n جهاز كمبيوتر مفتوحاً دائماً؟
إذا قمت بتشغيله محلياً نعم، ولكن يمكنك رفعه مجاناً على سيرفر سحابي مثل Render أو Google Cloud Run ليعمل 24/7 بدون انقطاع.

### هل نموذج DeepSeek R1 دقيق في اللغة العربية؟
نعم! يعتبر DeepSeek R1 من أفضل النماذج مفتوحة المصدر في فهم وصياغة اللغة العربية التقنية والتجارية بدقة عالية متفوقاً على العديد من النماذج الأخرى.

### هل يمكن توسيع البوت ليرسل إشعارات لإدارة المتجر؟
بالتأكيد، يمكنك إضافة نود Gmail أو Slack داخل n8n ليرسل لك تنبيهاً فورياً عندما يطلب العميل التحدث مع عنصر بشري!
