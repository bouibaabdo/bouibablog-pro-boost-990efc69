## 🛠️ كيفية الاستفادة من Cloudflare Workers AI مجاناً

توفر منصة Cloudflare للمطورين إمكانية استدعاء عشرات النماذج المفتوحة المصدر (مثل Llama 3 و Whisper لتفريغ الصوت) مجاناً عبر واجهة API بسيطة:

```javascript
// مثال استدعاء نموذج Llama 3 محلياً أو من السيرفر عبر Cloudflare Workers AI
async function runAIInference(env, promptText) {
  const response = await env.AI.run("@cf/meta/llama-3-8b-instruct", {
    prompt: promptText,
  });
  return response.response;
}
```

## 🎯 نصائح ذهبية لتعظيم الاستفادة من الأرصدة المجانية

1. **دمج N8N مع Google AI Studio:** احصل على مفتاح API مجاني من Google AI Studio واستخدمه كـ LLM ثابت داخل تدفقات الأتمتة.
2. **استغلال رصيد Modal التلقائي:** تمنحك Modal رصيداً شهرياً بقيمة 30 دولاراً يُعاد شحنه كل شهر، وهو كافٍ لتشغيل مئات مهام التفكير والـ Inference.
3. **تجنب الرصيد الضائع:** قم بإيقاف خوادم الـ GPU فور الانتهاء من التجربة حتى لا تستهلك الساعات التجريبية.
