# دليل ربط قاعدة بيانات Supabase PostgreSQL مع n8n وإدارتها بالذكاء الاصطناعي

تعد منصة **Supabase** البديل مفتوح المصدر الأكثر شعبية لمنصة Firebase، حيث توفر قاعدة بيانات **PostgreSQL** كاملة وقوية في السحاب مجاناً، بالإضافة إلى خدمات التوثيق (Auth) والتخزين والمستمعات الفورية (Realtime). عند دمج Supabase مع منصة الأتمتة **n8n**، يمكنك بناء تطبيقات ووكلاء ذكاء اصطناعي قادرين على قراءة وكتابة واستعلام البيانات تلقائياً دون كتابة كود معقد.

في هذا الدليل التفصيلي من **Bouiba Academy**، سنشرح خطوة بخطوة كيفية ربط Supabase مع n8n وبناء أتمتة كاملة لإدارة البيانات.

---

## لماذا تختار Supabase مع n8n؟

- **قاعدة بيانات PostgreSQL حقيقية:** دعم كامل للعلاقات، الـ Indexing، والاستعلامات المتقدمة.
- **تضمين الـ Vector Embeddings:** دعم ملحق `pgvector` لتخزين واسترجاع متجه السيمانتك (Semantic Search) للذكاء الاصطناعي.
- **مستوى مجاني سخي:** يتيح لك Supabase إنشاء مشروعين مجاناً بـ 500MB لكل قاعدة بيانات.
- **تكامل سلس مع n8n:** وجود عقدة (Node) مخصصة لـ Postgres وتكامل مباشر عبر REST & GraphQL APIs.

---

## الخطوة 1: الحصول على بيانات الاتصال من Supabase

1. قم بتسجيل الدخول إلى حسابك في [Supabase](https://supabase.com).
2. افتح مشروعك وانتقل إلى **Project Settings** -> **Database**.
3. ابحث عن قسم **Connection string** وقم بتحديد نوع الاتصال `Node.js` أو `URI`.
4. انسخ بيانات الاتصال التي تحتوي على:
   - **Host:** (مثال: `db.xxx.supabase.co`)
   - **Database Name:** (`postgres`)
   - **Port:** (`5432` أو `6543` للـ Connection Pooling)
   - **User:** (`postgres`)
   - **Password:** كلمة المرور التي اخترتها عند إنشاء المشروع.

---

## الخطوة 2: تهيئة الاعتمادات (Credentials) في n8n

1. افتح لوحة تحكم **n8n**.
2. انتقل إلى **Credentials** وقم بإنشاء اعتماد جديد من نوع **Postgres**.
3. أدخل البيانات التي نسختها من Supabase:
   - **Host:** أدخل رابط الـ Host الخاص بك.
   - **Database:** `postgres`
   - **User:** `postgres`
   - **Password:** كلمة السر الخاصة بك.
   - **SSL:** قم بتفعيل خيار `SSL` (مطلوب إجباري في Supabase).
4. اضغط **Save** للتأكد من نجاح الاتصال.

---

## الخطوة 3: بناء سيناريو الأتمتة واستعلام البيانات

سنقوم الآن ببناء سيناريو يستقبل طلبات جديدة ويقوم بحفظها مباشرة في جدول `users` داخل Supabase.

### 1. إضافة عقدة الـ Webhook

قم بإضافة عقدة `Webhook` في n8n لتعمل كمستقبل للطلبات بأسلوب `POST`.

### 2. إضافة عقدة Postgres

اختر عقدة **Postgres Node** ثم حدد العملية المطلوبة:

- **Operation:** `Execute Query` أو `Insert`.
- **Table:** `users`

في حالة استخدام `Execute Query`، يمكنك كتابة كود SQL مباشر مع متغيرات n8n:

```sql
INSERT INTO users (name, email, created_at)
VALUES (
  '{{ $json.body.name }}',
  '{{ $json.body.email }}',
  NOW()
)
RETURNING *;
```

## استخدام Supabase كـ Vector Store لـ n8n AI Agents

إذا كنت تبني بوت ذكاء اصطناعي يستند إلى مستنداتك الخاصة (RAG System)، يمكنك تفعيل ملحق `pgvector` في Supabase من خلال تشغيل الأمر التالي في SQL Editor:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

بعد ذلك يمكنك استخدام عقدة **Supabase Vector Store** الجاهزة داخل n8n لربط نماذج OpenAI أو Ollama وقراءة المستندات المخزنة بدقة متناهية.

## الأسئلة الشائعة (FAQ)

### هل يمكن الاتصال بـ Supabase من n8n المحلي؟

نعم بالتأكيد، سواء كنت تشغل n8n محلياً بـ Docker أو على سيرفر سحابي، يمكنك الاتصال بـ Supabase طالما تقع الخدمتان في نطاق الإنترنت المتاح وتفعيل خيار SSL.

### كيف أحمي البيانات من الوصول غير المصرح به؟

توفر Supabase نظام حماية قوي يدعى **Row Level Security (RLS)**. يوصى بتفعيل سياسات الـ RLS على جداولك لضمان عدم وصول أي جهة غير مصرح لها للبيانات الحساسة.
