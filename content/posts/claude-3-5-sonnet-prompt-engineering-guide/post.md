# دليل احتراف هندسة البرومبت لنموذج Claude 3.5 Sonnet للحصول على نتائج برمجية مبهرة

يعد نموذج **Claude 3.5 Sonnet** المطوّر من قبل شركة **Anthropic** المعيار الذهبي الحالي للذكاء الاصطناعي في مجالات كتابة الأكواد البرمجية، التحليل الدقيق، وتتبع المنطق البرمجي المعقد. ومع ذلك، فإن القدرة الحقيقية للنموذج تظهر فقط عند إتقان تقنيات **هندسة البرومبت (Prompt Engineering)** الخاصة به.

في هذا الدليل المتقدم من **Bouiba Academy**، سنكشف لك أسرار وتقنيات كتابة الأوامر الفعالة لاستخراج أفضل نتائج ممكنة من Claude 3.5 Sonnet.

---

## 1. استخدام وسم الـ XML Tags للهيكلة الدقيقة

على عكس النماذج الأخرى، تم تدريب نماذج Claude خصيصاً لتفهم وتستجيب بدقة عالية لوسوم XML مثل `<instructions>`, `<context>`, `<code_snippet>`, و `<output_format>`.

### مثال عملي:

```xml
<role>
أنت مهندس React و TypeScript خبير متخصص في كتابة كود نظيف وعالي الأداء.
</role>

<task>
قم بمراجعة الكود التالي وتحسين الأداء وإضافة التوثيق المناسب.
</task>

<code_snippet>
const calculateTotal = (items) => {
  return items.reduce((acc, item) => acc + item.price, 0);
}
</code_snippet>

<constraints>
- استخدم النوع الصريح TypeScript
- أضف التعامل مع الحالات الفارغة (Null checks)
- تجنب الاعتماد على مكتبات خارجية
</constraints>
```

## 2. تقنية "إعطاء النموذج مساحة للتفكير" (Chain-of-Thought)

عند مواجهة مشكلة برمجية معقدة أو ثغرة أمنية صعبة، لا تطلب من النموذج إعطاء الحل المباشر فوراً. بدلاً من ذلك، اطلب منه كتابة خطوات تفكيره أولاً داخل وسم `<thinking>`:

```text
يرجى تحليل الخوارزمية التالية.
قبل تقديم الحل النهائي، قم بتحليل المشكلة خطوة بخطوة داخل وسم <thinking> ووضح جميع الاحتمالات الممكنة، ثم قدم الحل البرمجي النهائي بعد ذلك.
```

تساعد هذه التقنية النموذج على تقليل الأخطاء المنطقية وزيادة دقة النتائج بنسبة تتجاوز 40%.

## 3. التوجيه بالأمثلة التوضيحية (Few-Shot Prompting)

تزويد النموذج بمثال أو مثالين لما تتوقعه يعطي نتائج أفضل بمراتب من الشرح النظري الطويل.

```xml
قم بتحويل الأوصاف التالية إلى كائنات JSON:

<example>
الوصف: أحمد، 28 سنة، مهندس برمجيات من المغرب.
الناتج:
{
  "name": "أحمد",
  "age": 28,
  "role": "مهندس برمجيات",
  "country": "المغرب"
}
</example>

الان قم بتحويل الوصف التالي:
الوصف: سارة، 32 سنة، مصممة واجهات من تونس.
```

## 4. نظام الأرسنال المباشر وتجنب الاعتذارات الإنشائية

يمتاز Claude 3.5 Sonnet باستجابته الممتازة للتعليمات التي تحدد أسلوب الإجابة بدقة. إذا كنت لا تريد مقدمات إنشائية طويلة مثل _"بالتأكيد، يسعدني مساعدتك في ذلك..."_، يمكنك تضمين الشرط التالي في بداية أمرك:

```text
أجب بشكل مباشر ودون أي مقدمات أو تحيات إنشائية. ابدأ بالحل البرمجي فوراً مع إضافة التعليقات التوضيحية داخل الكود.
```

## الأسئلة الشائعة (FAQ)

### ما الذي يميز Claude 3.5 Sonnet عن باقي النماذج؟

يمتاز النموذج بقدرة فائقة على فهم السياقات المعقدة وتوليد أكواد خالية من الأخطاء المنطقية، بالإضافة إلى ميزة **Artifacts** التي تتيح معاينة الواجهات والأكواد التفاعلية مباشرة بجانب المحادثة.

### هل تدعم تقنيات XML اللغتين العربية والإنجليزية معاً؟

نعم، وسوم XML تعمل بكفاءة عالية بغض النظر عن لغة النص المكتوب بداخلها، وتساعد النموذج على الفصل بين التعليمات والنصوص المترجمة.
