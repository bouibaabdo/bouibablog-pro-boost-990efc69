## 🎁 الهدية المجانية: ماذا تحتوي الحزمة؟

تحتوي الحزمة المجانية على 10 قوالب جاهزة مع كود التكوين والبرومبت المخصص لكل قالب:

1. **وكيل تلغرام الذكي (Telegram AI Agent Bot):** بوت تلغرام مجاني يجيب عن استفسارات العملاء بناءً على مستنداتك باستخدام Gemini API.
2. **أتمتة تلخيص وتفريغ الفيديوهات (YouTube Video Summarizer):** سحب نصوص الفيديوهات وتلخيصها في نقاط عمل مع تحويلها لمنشورات.
3. **مجدول المقالات والتدوينات التلقائي:** سحب اتجاهات الأخبار وتوليد مقالات سيو ومراجعتها قبل النشر.
4. **مراقب أسعار وتغيرات المواقع (Web Price Tracker):** إرسال تنبيه فوري لتطبيق Telegram عند انخفاض سعر أي منتج أو تغيير في صفحة.
5. **مساعد البريد الإلكتروني الذكي (Email Auto-Responder):** قراءة الإيميلات الواردة وتصنيفها وصياغة الرد المناسب تلقائياً.
6. **مُحلل منشورات التواصل الاجتماعي (Multi-Platform Content Generator):** تحويل أي رابط مقال إلى 5 منشورات مخصصة لـ Facebook و LinkedIn و X.
7. **بوت توليد الصور من الوصف (AI Image Generation Pipeline):** ربط تلقائي بين طلبات المستخدمين ومولدات الصور المجانية.
8. **مراقب السيرفرات والحماية (Server Health Monitor):** إرسال تنبيه عند توقف أي خادم أو زيادة الضغط على الذاكرة.
9. **مستخرج البيانات ومجمع الروابط (Web Scraping & Data Parser):** استخراج بيانات الجداول من المواقع وحفظها في Google Sheets أو Supabase.
10. **مساعد دراسي واختبارات تفاعلية:** تحويل النصوص التعليمية إلى أسئلة اختيارات وقوائم مراجعة.

## 🚀 كيفية استخدام قوالب n8n المجانية

استخدام القوالب بسيط جداً ولا يتطلب أي خبرة برمجية معقدة:

```bash
# 1. افتح لوحة تحكم n8n الخاصة بك (سواء كانت محلية أو سحابية)
# 2. اضغط على قائمة (Workflows) ثم اختر (Import from File) أو (Import from URL)
# 3. اختر ملف الـ JSON المرفق بالقالب
# 4. قم بإضافة API Keys الخاصة بك (مثل GEMINI_API_KEY أو Telegram Bot Token)
# 5. اضغط على (Activate) ليبدأ التدفق بالعمل تلقائياً!
```

## 💡 خطوات عمل نموذج أتمتة Telegram AI Agent في n8n

إليك بنية التدفق المباشر لبوت التلغرام الذكي:

```json
{
  "nodes": [
    {
      "parameters": {
        "updates": ["message"]
      },
      "name": "Telegram Trigger",
      "type": "n8n-nodes-base.telegramTrigger"
    },
    {
      "parameters": {
        "modelName": "models/gemini-2.5-flash",
        "options": {}
      },
      "name": "Google Gemini Chat Model",
      "type": "@n8n/n8n-nodes-langchain.lmChatGoogleGemini"
    },
    {
      "parameters": {
        "chatId": "={{ $json.message.chat.id }}",
        "text": "={{ $json.output }}"
      },
      "name": "Send Reply",
      "type": "n8n-nodes-base.telegram"
    }
  ]
}
```

## ❓ الأسئلة الشائعة (FAQ)

### هل يمكن تشغيل هذه القوالب على n8n المحلي (Self-Hosted)؟

نعم! جميع القوالب متوافقة 100% مع النسخة المجانية المستضافة ذاتياً عبر Docker أو السيرفر الشخصي.

### هل أحتاج إلى اشتراكات مدفوعة لاستخدام هذه التدفقات؟

لا، يمكنك استخدام نماذج مجانية مثل Google Gemini API أو نماذج Ollama المحلية بدون دفع أي سنت.

### كيف يمكنني تعديل البرومبت المرفق مع كل قالب؟

يمكنك النقر المزدوج على عقدة (AI Agent) في n8n وتغيير الـ System Prompt بسهولة ليتناسب مع مجال عملك.
